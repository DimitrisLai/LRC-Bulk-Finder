LRC BULK FINDER v2.4.4 — ENGLISH / ΕΛΛΗΝΙΚΑ WINDOWS GUI
Created by Dimitris L. — Open Source / Public Beta

1. Extract EVERYTHING from the v2.4.4 Standalone Windows GUI ZIP. Do not launch inside ZIP.
2. Keep LRC_Control_Center.exe and LRC_Bulk_Finder_Worker.exe beside CSV resources and bundled manuals.
3. Double-click LRC_Control_Center.exe. No Python install needed for normal searches.
4. Choose English / Ελληνικά in the top-right Interface language menu. The change happens live and is remembered.
5. Select your music folder from Saved searches / Αποθηκευμένες αναζητήσεις.
6. No huge offline LRCLIB database? Select Search action 1 (online). Actions 4/5 need a separately installed LRCLIB SQLite database.
7. First try 20 songs. Save a profile, click START SEARCH, and inspect Live progress.
8. Review uncertain .candidate.lrc manually; these are never automatically certified. Existing .lrc stays untouched by normal searches.
9. STOP stops the application worker tree. If process termination cannot be verified, check Windows Task Manager before restarting. Resume uses safe checkpoints.
10. Read the enclosed detailed English manual and Greek guide before full-library operations.

The large offline LRCLIB dump and optional heavy local Greek AI model are not bundled.
The public EXEs are unsigned. Verify official GitHub release and SHA-256 manifest; follow Windows security policy.
Original music files and tags are not modified by normal searches.
