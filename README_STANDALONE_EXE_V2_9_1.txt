LRC BULK FINDER v2.9.1 — IMPORTANT: WHICH FILE TO OPEN?

WINDOWS GUI (DOUBLE-CLICK):
  LAUNCH_LRC_BULK_FINDER_WINDOWS.cmd
or
  LRC_Control_Center.exe

DO NOT DOUBLE-CLICK:
  LRC_Bulk_Finder_Worker.exe
That EXE is a background worker for searches. If opened by itself, it correctly reports that --profile is required. It will not display the main interface.

STEP BY STEP
1. Right-click the official ZIP and choose Extract All. Keep both EXEs and the other files together.
2. Run LAUNCH_LRC_BULK_FINDER_WINDOWS.cmd (or LRC_Control_Center.exe).
3. The title should say LRC Bulk Finder v2.9.1 — Control Center, including after switching to Greek.
4. Choose your music folder, then Quick Search or Sync Lab > Smart Library/Karaoke Edition as needed.
5. Saved search profiles are started using the Control Center; it launches the Worker EXE with the proper arguments automatically.
6. If the Control Center does not appear, do not run the Worker EXE as a workaround. Confirm you extracted everything, try the launcher, and report exactly what appears on screen.
7. The blue Windows warning may remain until independent code signing is approved.
8. Verify the official SHA-256 manifest; consult the English and Greek PDF manuals, then follow your full-day pre-v3.0 test checklist.

This patch corrects display version, startup guidance and packaging validation only. Existing v2.9 Smart Library, karaoke and source-file safeguards are preserved.
