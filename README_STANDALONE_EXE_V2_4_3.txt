LRC BULK FINDER v2.4.3 — STANDALONE WINDOWS GUIDE
Created by Dimitris L. — Public Beta

1. Extract ALL files from LRC_Bulk_Finder_v2_4_3_Standalone_Windows_GUI.zip into a writable Windows folder.
2. Keep LRC_Control_Center.exe and LRC_Bulk_Finder_Worker.exe together with the bundled CSV dictionaries, LRCLIB_CONTACT.txt and any accompanying files.
3. Double-click LRC_Control_Center.exe. Python is NOT required for ordinary searches.
4. Select your music directory on the Saved searches tab. If you have a separately downloaded LRCLIB SQLite database, point Choose database to the .sqlite3 file. Do not redownload it needlessly.
5. First run: use 20 songs. Without the big SQLite, choose Search action 1. With it, try Greek Quick Test — 20 Songs.
6. Save your profile, then click Save profile and START SEARCH. Check Live progress, including four stage counters and two cumulative totals.
7. Click Candidate review to examine uncertain .candidate.lrc files. Never treat these as verified. Use Approve Greek alias... only after checking the correct spelling.
8. The Provider health tab reports actual observed status and real saved LRC events, not independent availability scans. SimpMusic is experimental and OFF by default; do not enable for a first search.
9. STOP SEARCH — keep app open requires confirmation. If child termination is not independently verified, check Windows Task Manager before starting again. Resume previous search restarts the last recorded unfinished profile, relying on safe checkpoints.
10. LRC_Skipped.txt lists missing-metadata tracks; Not Found and Timeouts remain separate. The provider contribution report shows which sources installed distinct verified sidecars.

IMPORTANT: The heavyweight Greek G2G AI model is not bundled in standalone EXE. Use complete Python/CMD ZIP and setup scripts to install optional AI.
Original MP3/FLAC/M4A/MP4/OGG/OPUS/WAV files and existing .lrc files are never modified by normal searches. The community EXEs are unsigned; verify source and hashes and follow Windows security policy.
