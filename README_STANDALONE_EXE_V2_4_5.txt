LRC Bulk Finder v2.4.5 — Portable Windows GUI / English + Ελληνικά

INSTALLATION
Extract ALL files from the ZIP to one writable directory.
Double-click LRC_Control_Center.exe.
Keep LRC_Bulk_Finder_Worker.exe and the included resources in the same folder.
Python is not required for the normal standalone experience.

WHAT'S NEW
- Quick Search: folder + 20 songs or all + optional Greek/Greeklish matching, without advanced settings.
- Results dashboard: read-only counts, filename search, status filters and CSV export.
- Timing repair: apply a uniform timestamp offset with preview, save as NEW UNVERIFIED numbered candidate.
- Manual Check for updates and locally saved privacy-safe diagnostics.
- Live English / Ελληνικά language switch (remembered).

SAFETY
The original audio, metadata and existing verified or unverified LRC sidecars are not overwritten.
A saved timing correction is marked [00:00.00] candidate and NOT automatically verified.
The dashboard's 'Has LRC' is only file existence, not accuracy certification.
No automatic executable updates, telemetry, or background upload.
If Windows displays a SmartScreen warning: this freeware is currently UNSIGNED. Verify the release URL and published SHA256 checksums; follow your security policy.

OPTIONAL FEATURES
Offline LRCLIB searches need an external large database, not the bundled Greek lexicon.
Optional model-heavy Greek G2G AI is available through the full Python/CMD edition only.
