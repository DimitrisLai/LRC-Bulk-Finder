What's new: LIBRARY MANAGER
• Results dashboard includes searchable file-status filters, why a candidate was rejected, and exactly-selected retries.
• Selected retries run only the chosen files, with FULL online providers. Prior negative-result cache is bypassed only for that explicit new search.
• Safe session undo removes ONLY unchanged sidecar .lrc / .candidate.lrc files explicitly created by that GUI search (and logged under your own APPDATA). Each is rechecked before removal against its recorded SHA256 and exact mtime. Existing LRC, original audio, ID3, user edits, reports and settings are protected.
• Undo doesn't work for searches made before v2.5.0, nor for separately edited/manual timing-repair files. Undo itself is permanent, and requires confirmation.
• The rejection details are from previous local CSV search reports and can be stale, not a live lyrics-provider lookup.

All previous Quick Search, provider modes, STOP/resume, candidate review, Timing repair, manual update checking and Greek UI controls remain.
