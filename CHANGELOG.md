# Changelog

## v2.1.4 — Public Beta

- Fixed history handling so review candidates are not remembered as final no-matches.
- Added clearer review-required lists and provider statistics.
- Added persistent handling for HTTP 429 cooldowns.
- Added LRCLIB contact configuration.
- Preserved provider-specific timeout-only retries, Greek AI support and non-destructive MP3 handling.

## v2.1.3 — Public Beta

- Tightened automatic artist/title and recording-version checks.
- Reduced automatic duration tolerance to 3 seconds.
- Saved unverified lyrics as review candidates rather than MP3 sidecars.
- Added run-report archives and optional completed-search history.

## v2.1.2 — Public Edition

- Prepared a generic distribution without personal music lists and with optional Greek AI setup and documentation.

See `RELEASE_NOTES.txt` for v2.1.4 release details.
