LRC BULK FINDER v2.7.0 — KARAOKE & PRECISION

1. Extract all files from the Windows standalone ZIP into the same folder.
2. Run LRC_Control_Center.exe; keep LRC_Bulk_Finder_Worker.exe in the folder.
3. Open Sync Lab (experimental) > Lyrics Studio.
4. Choose an instrumental MP3/WAV/FLAC/OGG audio track.
5. The matching .lrc opens automatically if present, otherwise choose Load LRC... and select your own timed lyrics. For untimed lyrics use Classic Sync Lab then From Classic Sync Lab.
6. Click the Precision & Karaoke inner tab and Open karaoke display. Esc closes and F11 toggles fullscreen; music playback remains controlled from Lyrics Studio.
7. Use A/B points, rewind 1/5 seconds, read-only waveform and adjustable nudge sizes. Inspect timing warnings.
8. Optionally use 0.75x or 1.25x if native VLC 64-bit is installed; if unavailable remain at 1x.
9. Fix timing and Save NEW UNVERIFIED candidate. The original audio, ID3 and .lrc always remain unchanged.
10. Read EN/EL manuals for drafts, keyboard shortcuts, compatibility export and privacy.

Karaoke does not automatically remove vocals, recognize songs, or supply copyrighted lyrics.
For source edition: optional `pip install soundfile python-vlc` and compatible native VLC for compressed waveform and adjustable speed.
Code signature is pending independent SignPath approval. Always check SHA256 checksums.
