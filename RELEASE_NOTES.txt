LRC Bulk Finder v2.1.14 -- Optional Official LRCLIB Auto Installer
Created by Dimitris L. | Public Beta

The Windows ZIP contains only the application and installer source; there is
NO lyrics database inside. The LRCLIB database was publicly reported almost
250 GB unpacked in August 2026 and is not appropriate for redistribution
inside a general-purpose GitHub release.

Normal search does not require the database.
Run SETUP_LRCLIB_DATABASE.cmd only if you want the massive optional offline
installation. It attempts discovery via the public LRCLIB JSON catalog, then an HTML fallback, asks permission,
lets you choose storage, downloads with progress, resumes when supported,
extracts, validates, and configures the application when the official service is available. The external catalog was not reachable during release testing.

The older manual importer is SETUP_LRCLIB_DATABASE_FROM_FILE.cmd.
Read HOW_TO_START_V2_1_14.txt and CHANGES_V2_1_14.txt before publishing.

NEW v2.1.14: CLEANUP_LRCLIB_DATABASE.cmd offers safe, explicit cleanup of downloaded and extracted LRCLIB files.
Installer prints actual completed file sizes and attempts to create a cleanup shortcut beside the database.
