LRC BULK FINDER v2.8.0 — KARAOKE EDITION / ΕΚΔΟΣΗ ΚΑΡΑΟΚΕ

1. Extract the ENTIRE standalone Windows ZIP (do not run the EXE from inside ZIP).
2. Keep LRC_Control_Center.exe and LRC_Bulk_Finder_Worker.exe together in the same folder.
3. Launch LRC_Control_Center.exe; choose English or Ελληνικά.
4. Sync Lab (experimental) > Karaoke Edition > Add audio files... (your local instrumentals).
5. Exact named LRC files are paired automatically, or attach your chosen timed LRC through Pair selected LRC...
6. Double-click a playlist song. It opens in Lyrics Studio, where the embedded player can play it. If audio device/codec fails use a supported format or separate player.
7. In Karaoke Edition, choose your audience theme, font size, next-line visibility, optional local background, target display and countdown.
8. Choose Open audience screen. F11 fullscreen; Escape closes; Space play/pause; Left/Right previous/next track.
9. Need calibration? Adjust lyric offset +0.1/+1 (delays lyrics) or -0.1/-1 (shows earlier). Offset changes only what you see. Apply offset to ALL lyric timestamps asks confirmation; the original LRC stays untouched.
10. Preview LRC export before saving. Save from Lyrics Studio creates only a new numbered UNVERIFIED candidate, never overwrites originals.
11. Playlist, last opened track, loop markers, preferences and display geometry are saved privately within APPDATA/LRCBulkFinder/karaoke_v280.json. No automatic playback starts on app launch.
12. Standard file-dialog/manual screen move always remain available if Windows native drag-and-drop or monitor enumeration fails.

Karaoke operates with preexisting instrumental audio and timed lyrics, does not remove vocals or do word-by-word timing.
Non-1x playback requires a separate compatible installed VLC; dragging files uses native TkDnD extension packaged for Windows.
Windows binaries are UNSIGNED unless and until separate independent SignPath approval completes.
Please read both manual PDFs, test with copied audio, and verify the SHA256 file.
