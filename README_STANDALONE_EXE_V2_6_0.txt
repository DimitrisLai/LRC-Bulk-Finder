LRC BULK FINDER v2.6.0 — WINDOWS STANDALONE GUI

Official project: https://github.com/DimitrisLai/LRC-Bulk-Finder
Project license: MIT (code only; lyrics remain subject to their rights).

This is a portable Windows package. Extract all files and keep both EXEs together.
Double-click LRC_Control_Center.exe. No separate Python installation should be necessary.
Set language to English or Ελληνικά. Open Sync Lab -> Lyrics Studio.

The integrated player uses pygame/SDL_mixer. Supported decoding varies; MP3/WAV/OGG/FLAC are intended formats. OPUS/M4A/MP4 may require an external player. Listening does not verify lyric accuracy.
Before saving edited timings, confirm that a new UNVERIFIED .candidate.lrc is created; originals are never modified.

The EXE may be unsigned until the SignPath Foundation application is approved.
Confirm official release SHA-256 hashes before installation. Do not disable Windows protections globally.
