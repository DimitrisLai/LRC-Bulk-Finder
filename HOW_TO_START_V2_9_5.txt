LRC Bulk Finder v2.9.5 — Updated Windows appearance

1. Extract the ENTIRE standalone Windows ZIP into a new folder; keep both EXEs, Greek dictionaries and g2g_sidecar.py together.
2. Start LRC_Control_Center.exe. Your music folder and saved searches do not need to be imported again.
3. At the top-right choose Appearance: Light or Dark. For Greek interface use Εμφάνιση: Φωτεινό or Σκοτεινό.
4. The selected appearance and interface language are saved together for the next launch.
5. Saved searches now scrolls to the Start Search button, even on a smaller screen.
6. Greenish/indigo metrics and primary buttons indicate interactive controls; STOP stays visibly distinct. All eight original tabs and the optional G2G setup remain available.
7. For initial testing use a copy of a small music folder and a 20-song preset. Changing colors alone never starts a scan or edits music/lyrics.
8. Keep the v2.9.4 folder until you're satisfied. Light mode is the default if settings are missing or corrupt.
