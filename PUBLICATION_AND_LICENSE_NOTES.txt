Before publishing this beta:
- TEST the downloadable ZIP on a clean Windows 10/11 PC with Python 3.10+.
- TEST live lyrics providers, rate-limit behavior, standard/remix/radio
  versions and the separate review-candidate workflow.
- EDIT LRCLIB_CONTACT.txt to include a real public project HTTPS URL or

Third-party Python packages are installed separately via pip, NOT

  AUEB gr-nlp-toolkit: Apache-2.0 project
See SOURCES_AND_CREDITS.txt for more source/provider details.

No private MP3 collection, user aliases, preloaded lyric database or
model weights are bundled. Provider services may disappear/change;
user metadata may be transmitted in search queries.
