LRC Bulk Finder v2.9.8 — Candidate Review Workbench

1. Extract the entire Windows ZIP into a fresh directory; keep the last working version as backup.
2. Start LRC_Control_Center.exe. Go to Candidate review.
3. Select your music folder in Saved searches. Candidate Review > Refresh candidates.
4. Check top counters: Total / Primary / Alternatives / Eligible / Blocked primary.
5. Click Audio, Candidate, Kind, Status, #, or Folder table headers to SORT; click again for reverse sort.
6. Use Status filter to show Primary eligible, Primary, Alternative, Already has LRC, or Missing/ambiguous audio; use Filter text to narrow.
7. Use Ctrl/Shift for multiple selections, or Select visible / Select eligible primaries. The right/bottom preview follows your focused candidate.
8. Promote selected primaries promotes ONLY eligible primary rows from the current selection; no alternatives. Confirm the warning (all new .lrc files remain MARKED with [00:00.00] candidate and UNVERIFIED).
9. Promote ALL eligible primaries acts on every eligible primary in the configured folder scope (including rows hidden by filters). Carefully check the confirmation count and sample filenames before accepting.
10. Stop batch safely finishes the current file and then stops. Existing .lrc never overwritten; MP3/ID3 never modified. Check final success/skipped/partial/error tally.
11. After a successful promotion, .candidate.2.lrc may move into primary .candidate.lrc for future review; it will not be auto-installed in the same batch.
12. For final acceptance, test with a COPY of a small directory containing .candidate.lrc and numbered alternatives before using your main collection.
